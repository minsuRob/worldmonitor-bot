# Paper-only stock desk (KRX + US)
**PAPER TRADING ONLY.** No real orders, accounts, wallets or broker logins. The Toss Securities Open API is used for
**quotes only** (`quotes.py` has no order/account/balance methods, a path allowlist and a forbidden-word assert; see
`manual/tests/test_toss_readonly.py`). Public read-only fallbacks: DART, Stooq, open.er-api, Finnhub. Macro context
comes from the self-hosted World Monitor Redis only (never `api.worldmonitor.app`).

Eight independent paper books, each funded with **₩1,000,000** (`config.START_BALANCE_KRW`; USD books are converted
once at `FX_START_KRW_PER_USD` 1400 ASSUMED minus `FX_CONVERSION_COST` 0.1% → `START_BALANCE_USD` ≈ $713.57).
The desk runs on named market **slots** (not a fixed 15-minute cycle): code-only slots are run by the box cron
(`manual/variants.sh due --run`), the three LLM slots (`krx_cb`, `krx_after`, `us_er`) are split into `prepare`
(box) → Claude CLI judge (Mac) → `finish` (box) and driven by the routine in `manual/ROUTINE.md`.
Korean docs: `docs/project/stockdesk/` (architecture, books, data sources, fill model, schedule, testing, Toss read-only).

## Books
The table is generated from `config.py` and each strategy's `PARAMS`/`OVERRIDES` via `Strategy.describe()`; after changing a
number run `python3 gen_rules_doc.py --write` (`--check` fails when a doc drifts; test: `manual/tests/test_rules_docs.py`).

Shared RISK is identical in every book and cannot be overridden by a plugin (`risk.PROTECTED_KEYS`): one position
<= 20% of equity at entry, book down >3% today -> no new entries, down >15% from peak -> halted (kv, user clears),
no mark for >1 trading day -> UNMEASURABLE, >3 trading days -> closed at the last price, 거래정지 -> HALTED,
관리종목/투자위험/정리매매/상장폐지 -> sold at this slot's price. Strategy exits run after RISK on the marks it wrote.

## Commands (box, from `stockdesk/`)
```bash
manual/variants.sh prepare <slot>              # screens -> jobs.jsonl (LLM books) + PENDING orders (numeric books); prints {runId, jobs, ...}
manual/variants.sh finish <runId> [--no-judge] # Mac results.jsonl -> decide -> PENDING orders (--no-judge: no buys, finish anyway)
manual/variants.sh slot <name>                 # fill slot: marks -> RISK -> fill PENDING -> strategy exits -> equity snapshot
manual/variants.sh due [--run]                 # code-only slots whose window is open and not yet run today (box cron */5)
manual/variants.sh report [--json]             # 8-book table from the ledgers
manual/variants.sh report --series daily|weekly [--since YYYY-MM-DD] [--json|--csv path]
python3 schedule.py --assignments              # slot table for manual/ROUTINE.md
python3 gen_rules_doc.py --write|--check       # rules tables
python3 manual/tests/test_toss_readonly.py     # and the other manual/tests/test_*.py (see docs/project/stockdesk/testing.md)
```
Mac judge step (repo root, same runner as the legacy desk on purpose):
`CLAUDE_CLI_MODEL=fable CLAUDE_CLI_EFFORT=medium CLAUDE_CLI_MAX_JOBS=40 desk/manual/mac/claude_cli_runner.sh claude-cli-runs/<runId>/jobs.jsonl`
Offline dry run: `STOCKDESK_FAKE_SNAPSHOT=1 STOCKDESK_CLAUDE_CLI_STORE=/tmp/stockdesk-cli manual/variants.sh prepare krx_after` (no HTTP).
`STOCKDESK_BOOKS=CB,MO` limits the enabled books (tests, staged rollout).

## Carried over from the coin desk (`desk/`, legacy, not running since 2026-10-29)
- Independent ledgers per book with the same schema shape (`common.BOOK_SCHEMA`), one SQLite file each.
- Common RISK runs first and is never loosened by a book (`PROTECTED_KEYS` + registry check instead of convention).
- `prepare` / `finish` split around the Mac Claude CLI judge; the same runner script and `jobs.jsonl`/`results.jsonl`
  format (`pipeline: "stock"`); broken result lines are skipped, missing results fail closed (`NO_JUDGE`).
- Judge model/effort recorded per decision (`vjudge.model`/`effort`, from `claudeModel`/`requestedEffort`) and shown by `report`.
- One shared fetch per slot with a DB cache (`market.db`) so every book sees the same data.
- Rules table generated from code (`gen_rules_doc.py`), `--check` test.
- Fixed-fraction sizing (`size_frac`) with RISK's cap (`cap_entry_value`), min order -> `ZERO`.
- Macro block from World Monitor Redis (`regime_context.py`, background only, never a rule input).
- Lock file with exit code 3, `routine_version` recorded in the cycle files, Korean-only alerts, `--no-judge` fallback.
