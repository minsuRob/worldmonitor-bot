# 가이드 파라미터 요약

출처: [게으른 빌더 — 그록 에이전트 7개로 트레이딩 팀 만드는 법](https://lazyowen.com/guides/grok-bot-trading-team-setup)
아래는 이 데스크에 적용한 값의 요약(직접 정리)이며 원문 전체가 아님. 실제 값은 `desk/config.py`.

## 공통
- 모의 잔고 **$1,000**. 실제 주문·지갑·키 없음.
- 파이프라인: SCAN → VET → BOOK → SIZE → FILLS → RISK. VET를 통과하지 않은 것은 SIZE로 가지 않음.
- 마감 보고 매일 **23:00 KST**. 장중 알림은 숫자가 **10% 넘게** 움직일 때만.

## 역할별 규칙
| 봇 | 핵심 규칙 |
|---|---|
| SCAN | DexScreener만, 15분마다. `liquidity.usd ≥ $10k`. 변화 속도로 순위, 최대 10개. 홀더 수를 모르면 null + 출처 표기(지어내지 않음). 최근 두 구간(m5·h1) 모두 매도>매수면 제외. 가격이 홀더보다 빨리 오르면 경고. WM이 죽으면 `degraded: true`. |
| VET | 7개 검사를 순서대로, 첫 거절에서 멈춤 → PASS / PASS_PARTIAL / REJECT. ① 최대 홀더 >5% (공용 Solana RPC, 무응답=거절) ② 유동성 <$10k 또는 주문의 50배 미만 ③ 홀더 정체 중 가격 상승 ④ 신호가 이미 `priceChange.h1`에 반영 ⑤ 단일 출처·검증 불가 뉴스 ⑥ 왕복 수수료 후 엣지 없음 ⑦ 30분 미만 신생 페어 + 유동성 감소. 하루 거절 10건 미만이면 경고. |
| BOOK | 시장 목록은 자체 호스팅 WM `list-prediction-markets?category=crypto`(dataAvailable=false 또는 fetchedAt=0이면 중단). 가격은 Kalshi·Polymarket(200이 아니면 건너뜀). 확실히 같은 질문일 때만 짝지음. 가격을 보기 전에 자기 확률을 정하고 엣지 **>8%**만. 48시간 지난 데이터 제외, 물타기 금지, 최대 **7개**. 크기는 요청만(결정은 SIZE). WM degraded면 휴식. |
| SIZE | Kelly, 계좌의 **6% 상한**(목표 아님). 묶이지 않은 현금에서만. 최소 주문 **$50**, 슬리피지 예산 **2%**. 밈코인은 진입당 1주문, 추가는 **+50% 확인 후 되돌림**에서 1회만. 현금<최소 주문이면 0과 이유. 수수료를 감당 못 하는 크기는 만들지 않음. |
| FILLS | 수수료 **0.45%, 최소 $0.95** → 실효 수수료 = max(0.45%×금액, $0.95)/금액, 너무 높으면 `FEE_FLOOR`(예: $20 → 4.75%). 2% 초과 슬리피지는 크게 표시. 부분 체결은 반올림 없이 부분으로 기록. 기준 이상 대량 보유자가 팔면 대기 후 보고. |
| RISK | **5분마다**, 자체 타이머, 최종 권한(아무도 뒤집지 않음). `avg_6h = volume.h24/4`, `ratio = volume.h6/avg_6h`, **ratio < 0.20 → 전부 청산**. 응답 없으면 2회 재시도 후 청산(측정 못 하는 포지션 = 보유하지 않는 것). 시총 +60%면 표시하고 유지, +50%까지 보유. |

## CHIEF(감독) 규칙 — 사용자 지정
- CHIEF는 포지션을 열거나, 크기를 정하거나, 닫지 않는다.
- 봇이 응답을 2번 놓치면 1번 재시작하고 기록.
- 같은 봇이 1시간에 2번 죽으면 데스크 중단, 아무것도 닫지 않고 보고(RISK는 계속 실행).
- WM이 비었거나 오류면 degraded 표시, BOOK 휴식. 밈코인 데스크는 DexScreener로 계속.
- READY는 3개 WM 체크가 모두 실제 데이터를 줄 때만. api.worldmonitor.app 사용 금지. 커밋 해시·지연 시간·손익을 지어내지 않음.

## 데스크에서 추가로 정한 가정 (가이드에 없음)
- 밈코인 Kelly 입력값은 **가정**: 승률 0.45, 손익비 1.5 (추정치 아님).
- VET ④ 기준: `priceChange.h1 ≥ 25%`.
- 체결 모델: 상수곱 AMM, 견적 준비금 ≈ 유동성/2.
- 가이드에 손절·익절·최대 보유 시간이 없어 추가하지 않음.
